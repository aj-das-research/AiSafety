# AAMAS 2027 submission files (paper 3780)

Upload to OpenReview:
- Main paper PDF: `AAMAS2027_paper3780.pdf` (8 pages of main text, references on pages 8-9, no appendix).
- Supplementary material: `AAMAS2027_paper3780_supplementary.zip` (contains `AAMAS2027_paper3780_supplement.pdf`, the appendix).

`aamas2027.tex` is in submission mode (`\withappendixfalse`). To view paper + appendix in one PDF,
set `\withappendixtrue` in `aamas2027.tex` (do NOT upload that version: an appendix inside the main PDF counts toward the 8 pages).
To rebuild the supplement on Overleaf, compile `aamas2027_supplement.tex` as the main document.
