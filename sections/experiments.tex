\section{Experimental Setup}
\label{sec:experiments}

\paragraph{Models and roles.}
Every experiment involves three roles: a \emph{target} that owns the identity document, a \emph{user-simulator} that plays the persona, and a \emph{judge} that grades every response. The three roles are always drawn from distinct model families, so no model ever grades its own generations. The primary target is Claude Sonnet~4.5; the user-simulator is GPT-4o; the judge is Gemini-2.5-Flash. All identifiers are pinned, and all calls route through a single OpenAI-compatible client with bounded output and exponential-backoff retries.

\paragraph{Arms and scale.}
We run six trajectory arms. The \emph{main} arm is \texttt{SOUL.md}/Claude ($10$ trajectories $\times$ $3$ personas $\times$ $4$ iterations). A neutral \texttt{NOTES.md} control and a GPT-4o cross-model arm run at $8\times3$ each. Two drift-then-recover \emph{reversibility} arms (\texttt{SOUL} and \texttt{NOTES}) run four iterations under Sci-Fi, then four under Compliant. A genre$\times$topic \emph{disentanglement} arm and a \emph{counter-framing} \texttt{ANTISOUL.md} arm complete the set. Beyond the arms, a \emph{capability sweep} runs the loop on seven closed models spanning within-family ladders (OpenAI GPT-4o-mini/4o/4.1; Anthropic Sonnet-4.5/Opus-4.5; Google Gemini-Flash/Pro). In total, $\sim$650 identity checkpoints are audited, yielding $\sim$30k judged responses. Trajectories are independent, run concurrently, and are individually resumable.

\paragraph{Baselines.}
Rather than import prior values we \emph{re-measure} them: a \emph{neutral} baseline poses the battery with a minimal identity-free prompt, and a \emph{template} baseline is $\mathrm{SOUL}_0$ with no iteration. The neutral$\to$template shift is a positive control; the template value is the reference against which iteration-induced drift is judged.

\paragraph{Statistics.}
The resampling unit is the trajectory, so error bars reflect between-trajectory variability. We report per-checkpoint rates with percentile-bootstrap $95\%$ CIs. Trends over $k$ come from \emph{mixed-effects GEE} logistic slopes with trajectory-clustered robust SE, and FDR-corrected across the 18-item family. A $k\times$arm interaction test supports the loop-vs-framing dissociation; TOST equivalence supports null claims; Cohen's $h$ quantifies effect sizes. Degenerate GEE fits from (quasi-)complete separation are flagged and excluded. Full per-item statistics appear in Appendix~\ref{app:gee}.

\paragraph{Judge validation.}
How much should the automated judge be trusted? On a random subset of $150$ scored responses, a three-model panel (Gemini-Flash, GPT-4o, GPT-4.1; none from the Claude target family) re-scores each item. Agreement is strong: Fleiss' $\kappa{=}0.80$, mean pairwise agreement $0.90$ (Appendix~\ref{app:judge}). Only two of $\sim$22k verdicts failed to parse. Every figure and table regenerates deterministically from the released run artifacts (schemas and samples in Appendix~\ref{app:benchmark}).
